# Moony Dreams — загрузочный экран

Белая версия: [`dist/demo-white.html`](dist/demo-white.html), готовый скрипт — [`dist/moony-loader-white.js`](dist/moony-loader-white.js).
Он подключается так же, как обычный лоадер. В основном скрипте белый фон включается через `MoonyLoader.show({ theme: 'white' })`.

Загрузочный экран для веба. Это один JS-файл без зависимостей и сетевых запросов: CSS и картинки вшиты внутрь (≈55 KB).
Код на ES5, работает в любом браузере и вебвью без сборщика.

Готовый файл: [`dist/moony-loader.js`](dist/moony-loader.js).

## Адаптивность

Размеры считаются от реального viewport при каждом `resize` / `orientationchange`:

| Формат | Компоновка |
|---|---|
| Портрет и квадрат (ширина/высота < 1.25) | Лиса сверху, под ней логотип, прогресс-бар, проценты |
| Альбом (≥ 1.25) | Лиса слева, справа логотип и прогресс-бар |

Небо рисуется на canvas: Млечный Путь, звёзды разной яркости и цвета, количество зависит от площади экрана.
Картинка одинаковая при каждом запуске и перерисовывается только при смене размера.
Сверху мерцают несколько ярких звёзд, изредка пролетает падающая звезда.

**Луна** растёт вместе с загрузкой. Она начинается с полумесяца той же формы, что знак на лбу маскота,
к 100% становится полной, а свечение при этом усиливается.
Она висит в углу напротив созвездия: справа сверху в портрете, слева сверху в альбоме.

**Созвездие лисы.** В свободной части неба (над контентом в портрете, справа в альбоме) оранжевое созвездие
в форме головы лисы соединяется линиями по мере загрузки. Последними загораются глаза и искра на лбу, как у маскота,
а на 100% созвездие вспыхивает, и только потом экран исчезает. В совсем маленьких окнах (например, 300×250) оно скрывается само.

Учитываются safe-area (чёлки), есть `prefers-reduced-motion`. Посмотреть все разрешения сразу можно в [`preview.html`](preview.html).

## Подключение

Проще всего перетащить `index.html` сайта на `pack-html5.bat` в корне репозитория: батник сам встроит лоадер и соберёт zip.
Ниже описано, как подключить лоадер вручную.

Вставьте скрипт **первым элементом `<body>`**, до остального кода, чтобы экран появился сразу:

```html
<body>
  <script>/* содержимое dist/moony-loader.js */</script>
  <script>
    var loader = MoonyLoader.show();
  </script>
  ...
```

Или без кода: `<script src="moony-loader.js" data-autoshow></script>`.

Дальше в коде приложения:

```js
MoonyLoader.setProgress(0.4);   // реальный прогресс 0..1 (необязательно)
MoonyLoader.finish(function () {
  // экран догрузил бар до 100%, плавно исчез и удалён из DOM
  startApp();
});
```

Если реального прогресса нет, бар сам плавно ползёт к 90% и добегает до 100% по `finish()`.

### Unity WebGL / Cocos и другие движки

Вызовите `MoonyLoader.show()` до старта движка, передавайте прогресс из колбэка загрузки
(например, `createUnityInstance(canvas, config, function (p) { MoonyLoader.setProgress(p); })`),
а `finish()` — когда первая сцена готова к показу.

## Опции `show()`

| Опция | По умолчанию | |
|---|---|---|
| `parent` | вся страница | Элемент, который нужно перекрыть (тогда `position: absolute`) |
| `minDuration` | `1200` | Минимум мс на экране, чтобы не мелькал при быстрой загрузке |
| `fakeProgress` | `true` | Автоматическое заполнение бара до 90% |
| `showPercent` | `true` | Показывать проценты |
| `starDensity` | `1` | Множитель количества звёзд (например, `0.5` — реже, `1.5` — гуще) |
| `meteors` | `true` | Падающая звезда раз в ~9 с |
| `onHidden` | — | Колбэк после исчезновения (то же, что аргумент `finish`) |

`MoonyLoader.show()` возвращает экземпляр с методами `setProgress`, `finish`, `destroy` (убрать сразу, без анимации).

## Изменение

Исходники лежат в `src/` (`moony-loader.js`, `moony-loader.css`), картинки берутся из `../assets/`.
После правок пересоберите файл (нужен Python с Pillow):

```bash
python loader/build.py
```
